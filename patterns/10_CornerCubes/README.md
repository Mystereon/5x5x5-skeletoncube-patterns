# 10: CornerCubes

Eight colour-shifting 2×2×2 corner cubes.

This example is a lightweight fixed-pattern wrapper around the shared master sketch. Keep its relative folder position intact, then open `10_CornerCubes.ino` in Arduino IDE. To alter the effect, change the matching `render...()` function in [../../SkeletonCubePatterns/SkeletonCubePatterns.ino](../../SkeletonCubePatterns/SkeletonCubePatterns.ino).
