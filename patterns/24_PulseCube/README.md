# 24: PulseCube

Reducing and expanding ping-pong wire cube.

This example is a lightweight fixed-pattern wrapper around the shared master sketch. Keep its relative folder position intact, then open `24_PulseCube.ino` in Arduino IDE. To alter the effect, change the matching `render...()` function in [../../SkeletonCubePatterns/SkeletonCubePatterns.ino](../../SkeletonCubePatterns/SkeletonCubePatterns.ino).
