# 09: MatrixRain

Dense green 3-D Matrix rain.

This example is a lightweight fixed-pattern wrapper around the shared master sketch. Keep its relative folder position intact, then open `09_MatrixRain.ino` in Arduino IDE. To alter the effect, change the matching `render...()` function in [../../SkeletonCubePatterns/SkeletonCubePatterns.ino](../../SkeletonCubePatterns/SkeletonCubePatterns.ino).
