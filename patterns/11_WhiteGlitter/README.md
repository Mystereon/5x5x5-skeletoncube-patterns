# 11: WhiteGlitter

Fast-fading random white voxel glitter.

This example is a lightweight fixed-pattern wrapper around the shared master sketch. Keep its relative folder position intact, then open `11_WhiteGlitter.ino` in Arduino IDE. To alter the effect, change the matching `render...()` function in [../../SkeletonCubePatterns/SkeletonCubePatterns.ino](../../SkeletonCubePatterns/SkeletonCubePatterns.ino).
